rotte esistenti

- GET /FBN/login.php -> form login HTML
- POST /FBN/login.php -> login form classico (sessione + redirect)
- POST /FBN/login.php con JSON -> login API inline
- GET /FBN/register.php -> form registrazione HTML
- POST /FBN/register.php -> registrazione form classica
- POST /FBN/register.php con JSON -> registrazione API inline
- GET /FBN/logout.php -> distrugge sessione e redirect login
- GET /FBN/sito/index.php -> home interna con elenco partite mock
- GET /FBN/sito/admin/dashboard.php -> dashboard admin protetta
- GET /FBN/sito/logout.php -> logout secondario (presente ma con redirect discutibile)

FastBetNow JWT/API
- POST /FBN/JWT/login_api.php -> login API con access token + refresh token
- /FBN/JWT/manage_permissions.php -> endpoint gestione permessi (usa token Bearer, non forza un metodo HTTP preciso)
- /FBN/JWT/refresh.php -> file incompleto, non e una rotta realmente funzionante nello stato attuale
- POST /FBN/api/sync-matches -> sincronizza partite da football-data.org e inserisce quote nel DB (protetto JWT, richiede CREA_PARTITA)
